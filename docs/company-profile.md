# Martina Cement Plc (fictional)

<img src="logo.png" alt="Martina Cement Plc" width="420">

Martina Cement Plc is an invented company that gives this dashboard a
realistic setting. It has no connection to any real business, and every
customer, order, truck, person and number in the project is generated.

| | |
| --- | --- |
| Tagline | Strength you can build on |

| Headquarters | Victoria Island, Lagos (fictional) |

## Brand

The mark is a hexagon, a nod to the crystal structure of cement, holding an
M drawn as two rising walls with an amber sun above a foundation line.

| Colour | Hex | Use |
| --- | --- | --- |
| Martina teal | `#0E5E6F` | Brand, primary actions |
| Deep slate | `#0B2E3B` | Headings |
| Kiln amber | `#F2A541` | Accents, forecasts |
| Ink | `#1F2A33` | Text |
